      MCP（模型上下文协议）让 Agenite 接入外部工具服务器——浏览器自动化、桌面/电脑控制、数据库、GitHub 等。连上后它们会变成模型可调用的工具（名字以 mcp__ 开头）。这正是它从"聊天框"变成"智能体"的关键。
      

          
      
            工具市场 · 精选 MCP 服务器（点一下即接入）
            
      MCP 让本地 Agent 即插即用地桥接整个工具生态——浏览器、文件系统、代码仓库、搜索、数据库……无需写一行集成代码。这正是 Agenite「单文件 + 本地优先 + 数据不出本机」却能对标云端智能体的关键。

            上下文与轮次
            
      长任务会把对话撑爆模型的上下文窗口，导致直接报错。开启自动压缩后，旧的工具输出会先被裁剪，再不够就把最老的几轮总结成一段摘要保留下来。
      
          
      
          
          
          
      
            
            
          
      

          
      
            预算护栏（运行自检）
            
      交互式对话累计花费达到该上限时，自动注入「停止并总结」指令——防止智能体死循环或失控烧钱（2026 年 Agent 护栏基线）。填 0 表示使用默认上限 $3。自治目标有独立的预算设置，不受影响。
      
          
      
          
      
            
          
      

          
      
            成本估算
            
      内置常见模型的价格表。若你的价格不同（企业折扣、代理转发），在这里填写每百万 token 的单价来覆盖；填 0 表示用内置价格。本地模型恒为 0。
